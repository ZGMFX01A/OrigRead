Community release notes for August

This release focuses on editor stability, media handling, and accessibility. The fixture intentionally resembles a common WordPress article structure while containing entirely original test text.

Editor recovery now preserves draft blocks after an interrupted save. Media uploads report individual failures, and keyboard navigation is more consistent across settings panels.

Site maintainers should review the upgrade guide before deploying to production. Existing themes remain compatible with the documented public APIs.

Additional fixes improve cache invalidation and reduce repeated database queries on archive pages.
