Improving repository search reliability

Repository search must remain predictable when projects contain generated files, vendored dependencies, and several programming languages. This offline fixture describes a deterministic indexing pipeline used only for parser regression tests.

The pipeline first classifies files, removes ignored content, and records stable document identifiers. Query execution then combines lexical matches with structural hints so that exact symbols are not hidden by semantically similar results.

We also added bounded retries and clearer diagnostics. The implementation details are available in the engineering notes, including examples for large monorepositories.

These changes reduce index churn and make failures easier to reproduce without requiring remote services during local development.
